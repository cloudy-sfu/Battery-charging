Column descriptions
Variable Data type (validation) Description
Energy capacity number (MWh), > 0 Total energy capacity of the battery. The unit must align with the unit used by the load time series.
Initial level number, [0, 1] Initial state of charge as a fraction of energy capacity.
Max charging power number, > 0 Maximum input power. Unit is the energy-capacity unit per hour (e.g. MW when capacity is in MWh).
Max discharging power number, > 0 Maximum output power. Unit is the energy-capacity unit per hour (e.g. MW when capacity is in MWh).
Charging efficiency number, (0, 1) Round-trip charging efficiency.
